# Lab 1: Multi-Page SPA

1. Create three components: `HomeComponent`, `ProductsComponent`, and `AboutComponent`.
2. Define their routes in `app.routes.ts`.
3. Create a `<nav>` in `app.component.html` that uses `routerLink` to navigate between them.
4. Add `routerLinkActive="active"` to each link to style the current page.
5. Create a `NotFoundComponent` and map it to the `**` route. Test it by typing a random URL.
