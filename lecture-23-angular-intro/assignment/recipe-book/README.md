# Recipe Book App (Angular v21)

This folder represents the scaffold for the Recipe Book application. 

## To generate this project for real:
Run the following Angular CLI command in your terminal:
```bash
ng new recipe-book --style=css --ssr=false
```

- `src/app/app.component.ts` (Root Component)
