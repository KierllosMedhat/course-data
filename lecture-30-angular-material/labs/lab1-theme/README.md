# Lab 1: Custom Theme Setup

1. Open your terminal and run `ng add @angular/material`.
2. Follow the prompts. Choose a custom theme, and allow it to set up typography and animations.
3. In `app.component.ts`, import `MatButtonModule` and `MatCardModule`.
4. In `app.component.html`, add `<button mat-raised-button color="primary">Hello Material!</button>` and verify it works!
