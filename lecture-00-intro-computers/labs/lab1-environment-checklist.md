# Developer Environment Checklist

Use this checklist to ensure your computer is ready for the Full-Stack Web Development course.

## 1. Visual Studio Code
- [ ] Download from https://code.visualstudio.com/
- [ ] Install the application
- [ ] Open VS Code and open the Extensions tab (`Ctrl+Shift+X`)
- [ ] Install **Live Server** (by Ritwick Dey)
- [ ] Install **Prettier - Code formatter** (by Prettier)
- [ ] Install **Material Icon Theme** (by Philipp Kief)
- [ ] Install **Auto Rename Tag** (by Jun Han)
- [ ] Install **ESLint** (by Microsoft)

## 2. Node.js
- [ ] Download the **LTS (Long Term Support)** version from https://nodejs.org/
- [ ] Run the installer (leave all default options checked)
- [ ] Verify installation: Open terminal and type `node -v`
- [ ] Verify npm installation: Type `npm -v`

## 3. Git
- [ ] Download from https://git-scm.com/
- [ ] Run the installer
  - *Tip for Windows: When it asks for the default editor, you can choose "Use Visual Studio Code as Git's default editor"*
- [ ] Verify installation: Open terminal and type `git --version`

## 4. Browser
- [ ] Install Google Chrome or Microsoft Edge
- [ ] Verify you know how to open Developer Tools (`F12` or right-click -> Inspect)

Once you've checked all these boxes, you are ready to start coding!
